# 主论文模板使用说明

这份说明给准备手动操作的同学。不需要 Agent，也不需要学习编程或 LaTeX。日常只做三件事：填写 `论文信息.md`、在 `论文.md` 中写论文、双击“生成论文”。

## 一、解压并保留完整文件夹

把 `main-thesis-template.zip` 解压到容易找到的位置。解压后应看到 `论文信息.md`、`论文.md`、`生成论文.command`、`生成论文.bat`、`images`、`scripts`、`template` 和 `output`。

请保留整个文件夹，不要只把 `论文.md` 移走。本包生成主论文，不含任务书、考核表、文献综述、开题报告和书脊。

## 二、第一次安装软件

需要 Markdown 编辑器、Python 3、Pandoc 和 TeX 排版环境。推荐用 Typora 写作，但 Typora 不参与 PDF 生成，也可以换其他支持 UTF-8 的 Markdown 编辑器。

### macOS

1. **Typora（写作软件）**：打开 <https://typora.io/#download>，下载 macOS 版本，把 Typora 拖入“应用程序”。在“设置/偏好设置 → 图像”中，建议把插入图片时的处理方式设为“复制图片到 `./images` 文件夹”。
2. **Python 3**：打开 <https://www.python.org/downloads/macos/>，下载 macOS 64 位安装包并默认安装。打开“终端”，执行 `python3 --version`，看到 `Python 3.x.x` 即可。若提示安装“命令行开发者工具”，按提示安装。
3. **Pandoc**：打开 <https://pandoc.org/installing.html>，下载 macOS `.pkg`。Apple 芯片选 `arm64`，Intel 选 `x86_64`，默认安装。重新打开终端，执行 `pandoc --version`。
4. **MacTeX**：打开 <https://www.tug.org/mactex/>，下载完整 `MacTeX.pkg` 并默认安装，预留数 GB 空间。重新打开终端，执行 `/Library/TeX/texbin/xelatex --version`，看到 `XeTeX` 即可。建议使用完整 MacTeX，避免缺少中文宏包和字体。

安装后，在终端输入 `cd `（有空格），把本模板文件夹拖进终端并按回车，然后执行：

```bash
python3 scripts/build.py --check
```

### Windows 10 / 11

1. **Typora（写作软件）**：打开 <https://typora.io/#download>，下载 Windows 64 位版本并默认安装。在“偏好设置 → 图像”中，建议把插入图片时的处理方式设为“复制图片到 `./images` 文件夹”。
2. **Python**：打开 <https://www.python.org/downloads/windows/>，下载 Windows 64 位安装包。**先勾选 `Add python.exe to PATH`，再点击 `Install Now`。**打开新的命令提示符，执行 `python --version`。
3. **Pandoc**：打开 <https://pandoc.org/installing.html>，下载 Windows `.msi` 并默认安装。重新打开命令提示符，执行 `pandoc --version`。
4. **MiKTeX**：打开 <https://miktex.org/download>，下载 Basic Installer 并默认安装。缺少宏包的处理方式选择自动安装或询问后安装，不要选从不安装。打开 MiKTeX Console 检查更新，再在新命令提示符执行 `xelatex --version`。第一次生成时可能联网下载宏包，请选择允许。

安装后，在本模板文件夹地址栏输入 `cmd` 并按回车，然后执行：

```bat
python scripts\build.py --check
```

看到“基础程序、TeX 宏包和字体检查通过”后，还要继续做一次完整示例生成。

## 三、先测试原始示例

先不要改内容。macOS 双击 `生成论文.command`，Windows 双击 `生成论文.bat`。等待三次排版完成，最后显示：

```text
生成完成：output/毕业论文.pdf
```

程序会尝试打开 PDF，也可以到 `output` 文件夹打开。建议检查封面、目录、正文、参考文献、附录和作者简介。

建议先复制一份完整模板文件夹，保留原始模板，在副本中填写自己的内容。

## 四、填写个人信息

打开 `论文信息.md`，只修改冒号后面的内容：

```text
西语题目：在这里填写西语题目
中文题目：在这里填写中文题目
姓名：在这里填写姓名
学号：在这里填写学号
指导教师：在这里填写导师姓名
年级与专业：在这里填写年级和专业
所在学院：外国语学院
提交日期：在这里填写提交日期
论文性质：公开
```

字段名不能改，所有字段都要填写。`论文性质`只能写`公开`或`涉密`。姓名只有两个字时，中间空一个汉字位置，例如`徐 丹`。示例中的姓名、学号、年级和日期都要替换。保存后再生成。

## 五、在论文.md 中写作

### 1. 分区标记

按顺序保留以下独立行：

```text
【致谢】
【西文摘要】
【中文摘要】
【正文】
【参考文献】
【附录】
【作者简介】
```

只替换标记之间的示例内容。不要改名、重复或调换顺序。不需要附录或作者简介时，清空该部分示例文字，但保留标记行。

`<!--`和`-->`之间的是提示，不会出现在 PDF 中。

### 2. 标题和正文

```markdown
# 一级标题

## 二级标题

### 三级标题

#### 四级标题
```

`#`后要有空格。不要手写`1`、`1.1`等编号，程序自动编号。

普通正文直接书写，段落之间空一行。不要在段首敲空格，也不要用连续空行控制分页。字体、首行缩进、两端对齐和行距自动处理。正文一级标题会按双面排版规则另起奇数物理页，中间可能出现空白页。

Typora 预览只用于写作，最终格式以生成的 PDF 为准。

### 3. 摘要关键词

西文摘要末尾写：

```text
Palabras clave: Español; chino mandarín; difusión internacional
```

中文摘要末尾写：

```text
关键词：西班牙语；汉语普通话；国际传播
```

### 4. 文内引用、长引用和脚注

文内引用直接写，例如 `(Cooper 1982:13)`。长引用使用：

```markdown
> 这里填写较长的引用内容。
>
> （Autor 2020：25）
```

脚注使用：

```markdown
正文中的脚注标记。[^1]

[^1]: 这里填写脚注说明。
```

## 六、参考文献

在【参考文献】下每条单独一行，不写序号：

```text
Baker, M. Routledge Encyclopedia of Translation Studies[M]. Shanghai: Shanghai Foreign Language Education Press, 2010.
Cooper, R. L. A Framework for the Study of Language Spread[J]. Language Spread: Studies in Diffusion and Social Change, 1982, 5: 36.
朱湘军. 从权力与话语看翻译之强势[J]. 外国语, 2008(6): 23-38.
```

程序自动生成 `[1]`、`[2]` 和悬挂缩进。

**程序不会自动把任意文献信息转换成学院要求的完整格式。**作者、年份、题名、文献类型 `[M]`/`[J]`、出版地、出版社、卷期、页码和标点仍由你按学院模板填写。提交前必须人工核对。本程序也不检查篇幅、文献数量、外文文献数量或文献比例。

## 七、图片、表格和公式

### 图片

把图片放入 `images`，图片单独占一个段落：

```markdown
![这里填写图题](images/mi-figura.png){width=12cm}

Fuente: Elaboración propia.
```

图号自动生成，不要手写`Gráfico 1.`。`width=12cm`可以改为`8cm`、`10cm`等，不要超过正文宽度。来源行可省略。

### 表格

```markdown
| Partes | Aspectos | Indicadores |
|:---|:---|:---|
| Tracción del mercado | General | Índice de Poder |
| Empuje del gobierno | Gobierno | Aportación |

Tabla: 在这里填写表题

Fuente: Elaboración propia.
```

表号自动生成，表题在表格下方。超过一页的大表建议手动拆分。表题和来源中的 `&`、`%`、`#`、`_` 等直接写，不要添加反斜杠。

### 公式

```markdown
$$
U = 3X
$$
```

独立公式自动按章节编号，例如`(3-1)`。行内变量写作 `$U$`。

## 八、每次修改后生成

1. 保存 `论文信息.md` 和 `论文.md`。
2. 建议关闭正在打开旧 PDF 的阅读器。
3. 双击对应系统的“生成论文”文件。
4. 等程序完整结束，看到“生成完成”后再打开 `output/毕业论文.pdf`。

不要使用 Typora 自带的“导出 PDF”作为提交文件，那不会应用本模板格式。

失败时，旧 PDF 会移到 `output/毕业论文.previous.pdf`；成功生成新 PDF 后备份自动删除。`build` 是中间目录，不要手改。

## 九、常见问题

- **找不到 `pandoc` 或 `xelatex`**：确认安装成功，关闭并重新打开终端和生成窗口。macOS 可执行 `pandoc --version` 和 `/Library/TeX/texbin/xelatex --version`；Windows 执行 `pandoc --version` 和 `xelatex --version`。
- **Windows 找不到 `python`**：重新运行 Python 安装程序并勾选 `Add python.exe to PATH`，再打开新的命令提示符。
- **macOS 双击 .command 没反应**：右键文件选择“打开”。若提示没有执行权限，在模板目录的终端执行 `chmod +x 生成论文.command`。
- **缺少 `.sty` 文件**：这是 TeX 宏包缺失。macOS 建议完整 MacTeX；Windows 允许 MiKTeX 安装宏包，或在 MiKTeX Console 中安装。
- **缺少字体**：确认有 Times New Roman。中文需要仿宋、宋体、黑体，或 TeX 的 Fandol 中文字体；Windows 可在 MiKTeX Console 安装 `fandol`。
- **分区错误**：对照第五节恢复全部 7 个标记，使用中文方括号，保持名称和顺序，不要用原始示例覆盖已写内容。
- **图片不显示**：检查 `images` 中的实际文件名、扩展名和 Markdown 路径，不要使用原电脑绝对路径。
- **目录或页码不对**：让三次排版全部完成，不要中途关闭窗口，然后再正常生成一次。
- **无法写入 PDF**：关闭旧 PDF 阅读器，确认文件夹可写。

需要详细错误时，保留生成窗口内容，并查看 `build/xelatex-pass-N.txt`、`build/thesis.log`；环境检查失败时查看 `build/environment-check.txt`。向 Agent 或技术人员求助时一起提供这些日志。

## 十、提交前检查

- 封面字段不是示例，公开/涉密选择正确。
- 总目录、正文目录、标题和页码已更新，正文从 1 开始。
- 图号、表号、公式号和文内引用一致。
- 参考文献格式已按学院要求人工核对。
- 图片和表格清晰，没有超出页面。
- 不需要的附录和作者简介已清空示例内容。
- 打印预览中的空白页位置正确。

本模板只生成 PDF，不生成 Word。如果学院要求 Word，需要另行处理并重新检查全部格式。
